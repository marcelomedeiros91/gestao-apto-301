Acessar no Computador e Celular (GitHub + Nuvem Google)

Como publicar no GitHub e sincronizar com sua Planilha Google:

  1. No seu GitHub, crie um repositório novo, envie este arquivo com o nome index.html e ative o GitHub Pages em Settings → Pages.
  2. Para que o celular e o computador compartilhem os lançamentos automaticamente, crie uma Planilha no Google Drive, clique em Extensões → Apps Script e cole o código abaixo:
function doGet(e) {
  var prop = PropertiesService.getScriptProperties().getProperty('APTO301_DATA');
  return ContentService.createTextOutput(prop || '{}')
    .setMimeType(ContentService.MimeType.JSON);
}

function doPost(e) {
  var body = e.postData.contents;
  PropertiesService.getScriptProperties().setProperty('APTO301_DATA', body);
  return ContentService.createTextOutput(JSON.stringify({status: 'ok'}))
    .setMimeType(ContentService.MimeType.JSON);
}

Depois clique em Implantar → Nova implantação → App da Web (Quem pode acessar: Qualquer pessoa), copie a URL gerada e cole no campo acima!
